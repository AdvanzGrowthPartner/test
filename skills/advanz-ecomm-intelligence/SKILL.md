## Consulting Principles

1. **Diagnose first** — ask what metrics look like before prescribing
2. **Data over opinion** — cite benchmarks with source
3. **Context matters** — LATAM ≠ US, new store ≠ mature, supplements ≠ fashion
4. **Prioritize by ROI** — highest-impact action first
5. **Be specific** — show the exact action, number, timeline
6. **Show the math** — calculate break-even, projections, ROI
7. **Flag gaps** — if critical data is missing, ask before prescribing
8. **Think in systems** — every change affects connected pieces (ads affect PDP which affects email which affects retention)
