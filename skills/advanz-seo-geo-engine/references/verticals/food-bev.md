# Vertical: Alimentos Funcionales y Bebidas

Etiqueta limpia. Certificaciones múltiples. Categoría regulada.

## Particularidades

- **Regulación fuerte** — Ministerio de Salud, sello negro/octógono Chile
- **Etiqueta limpia es diferenciador** — sin azúcar, sin colorantes, vegano, keto
- **Categoría altamente educativa** — gente quiere entender qué consume
- **Sabor + función dual** — vender placer + beneficio
- **Estacionalidad** — verano (hidratación), invierno (inmunidad)

## E-E-A-T

- Nutricionistas colegiados
- Tecnólogos en alimentos
- Certificaciones: registros sanitarios, sello orgánico, FairTrade, kosher si aplica
- Información nutricional en HTML obligatoria

## Schema específico

- `Product` + `NutritionInformation`
- `Recipe` si hay recetas con el producto
- `suitableForDiet` (KetogenicDiet, VeganDiet, GlutenFreeDiet)
- AggregateRating
- `manufacturer`

## Pillar y cluster típico

**Pillar:** "Mejores [categoría alimento] en Chile 2026"

**Soportes informacionales:**
- "Beneficios de [ingrediente principal]"
- "Por qué consumir [tipo alimento]"
- "Diferencias entre [versión convencional] y [versión funcional]"

**Soportes comparativos:**
- "[Marca A] vs [Marca B]"
- "[Tipo producto A] vs [Tipo producto B] (kombucha vs kéfir)"

**Soportes caso de uso:**
- "[Producto] para [dieta específica]"
- "[Producto] en embarazo"
- "[Producto] para niños"
- "Recetas con [producto]"
- "[Producto] para [actividad/momento]"
