## 1. Los 9 tipos de hook

El hook es lo único que decide si el video se ve o se saltea. Debe abrir un loop o detener el scroll en <3s.

1. **Relatable / Situación** — "Cuando [situación ultra-específica del avatar]…". Espejo. Mientras más específico, más amplio el alcance.
2. **Provocación / Contrarian** — "Dejá de [hábito aceptado]" / "Nunca [cosa que todos hacen]". Disonancia.
3. **Número / Resultado** — "[Cantidad exacta] en [tiempo]". Los números esquivan el filtro de escepticismo. Números impares > redondos.
4. **Curiosidad gap** — "[Pista parcial] + info retenida". Efecto Zeigarnik: el cerebro busca cierre.
5. **Pregunta directa** — "¿[Pregunta que el avatar se hace internamente]?". Activa búsqueda mental de respuesta.
6. **Mini-historia** — "[Personaje] + acción + giro inesperado". Narrativa = momentum.
7. **Identidad / Tribu** — "Si eres [rol], esto es para ti". Espejo + pertenencia.
8. **Autoridad / Tercero creíble** — nombre, credencial o testigo que presta credibilidad.
9. **Shock visual** — acción o imagen que rompe el patrón del feed en el primer frame.

**Reglas de hook:**
- Máximo ~12-15 palabras si es hablado o texto en pantalla.
- El hook debe ser coherente con el ángulo (no prometer una cosa y entregar otra).
- Lo mejor: stackear 2 tipos (ej. Número + Curiosidad: "Probé esto 30 días y pasó algo que no esperaba").
- Para video con persona: el hook puede ser lo que DICE, lo que MUESTRA, o ambos.

## 2. Estructuras narrativas de guión

### Estructura A — Pain-Solution (la más versátil)
```
Hook (dolor o situación) → Agitar el problema (que duela un poco) →
Puente ("hasta que descubrí…") → Solución/producto →
Demostración o prueba → CTA
```
Mejor para: avatar consciente del problema. Ángulos Dolor→Alivio, Identidad.

### Estructura B — Testimonial / Reseña honesta
```
Hook (escepticismo o resultado) → Contexto de quién soy y mi situación →
"No esperaba que funcionara, pero…" → Qué cambió (específico) →
Recomendación → CTA
```
Mejor para: prueba social. Presenter = cliente real o UGC. Desarma "otro producto más".

### Estructura C — Educativa / Autoridad
```
Hook (mito o dato sorprendente) → "La mayoría cree X, pero…" →
Explicación de valor (enseña algo real) → Cómo el producto encaja →
CTA suave
```
Mejor para: avatar inconsciente o confundido. Presenter = fundador/experto.

### Estructura D — Antes/Después narrado
```
Hook (el antes o el después impactante) → Cómo era antes (relatable) →
El punto de quiebre → El cambio → Cómo es ahora → CTA
```
Mejor para: transformación. Cuidar claims en salud.

### Estructura E — Día en la vida / Demostración integrada
```
Hook (situación cotidiana) → Rutina con el producto integrado naturalmente →
Momento de uso (demostración) → Beneficio en contexto → CTA casual
```
Mejor para: producto que se usa a diario. Tono UGC, poco vendedor.

### Estructura F — Tercero como testigo
```
Hook (sobre otra persona) → Por qué me importa esa persona →
El problema que tenía → Qué cambió con el producto → CTA
```
Mejor para: alta credibilidad. Ej. hija sobre mamá, esposo sobre esposa.

## 3. Cómo escribir para que suene a persona, no a marketing

- Escribir como se habla: frases cortas, contracciones, muletillas naturales ("o sea", "la verdad", "te juro").
- Prohibir lenguaje de folleto: "potencia tu bienestar", "fórmula avanzada", "solución integral".
- Usar el lenguaje del cliente (sus palabras exactas para el dolor), no el de la marca.
- Permitir imperfección: una pausa, un "no sé cómo explicarlo pero…" suena real.
- Una idea por frase. Si una frase necesita coma para respirar tres veces, cortarla.
- Leer en voz alta mentalmente: si no se puede decir sin trabarse, reescribir.

## 4. Guion por tipo de presenter

| Presenter | Cómo entregar el guión | Qué fijar / qué dejar libre |
|---|---|---|
| **UGC creator** | Guía de mensaje + estructura | Fijar: hook, ángulo, CTA. Libre: palabras exactas. |
| **Cliente real (testimonial)** | Guía de preguntas | No dar guión rígido; dar preguntas que provoquen la respuesta. |
| **Fundador / vocero** | Guión con espacio para autenticidad | Fijar mensaje clave; permitir su voz natural. |
| **Actor** | Guión más cerrado | Puede ser más literal, pero igual debe sonar natural. |

Para testimoniales, en vez de "decí que el producto te cambió la vida", entregar preguntas como: "¿Cómo era tu día antes de usarlo?" "¿Cuándo notaste el cambio?" "¿Qué le dirías a alguien que duda?".

---

## 5. El CTA: cómo cerrar

- El CTA es consecuencia del ángulo, no un pegote. Un video de dolor→alivio cierra distinto que uno educativo.
- Incluir la oferta activa si existe (descuento, garantía, bundle) — define la fuerza del cierre.
- Tipos: directo ("andá al link"), suave ("si te pasa lo mismo, mirá la descripción"), con urgencia ("hasta el domingo"), con garantía ("si no te funciona, te devuelven la plata").
- Una sola acción. No pedir "seguinos, comentá y comprá" — un solo siguiente paso.

## 6. Checklist de calidad del guión

Antes de entregar, verificar:
- [ ] El hook detiene el scroll en <3s y es coherente con el ángulo.
- [ ] Hay UN argumento central, no varios compitiendo.
- [ ] Suena a persona real, no a folleto.
- [ ] El claim es honesto y (en salud) legalmente permitido.
- [ ] El presenter recomendado encaja con el ángulo.
- [ ] El CTA es una sola acción y consecuencia natural del video.
- [ ] La oferta (si existe) está integrada en el cierre.
- [ ] No hay jerga técnica de producción mezclada (eso va aparte si se pide).
