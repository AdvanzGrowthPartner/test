# Ads Intelligence — Pauta Digital Competitiva

## Fuentes de investigación

### Meta Ad Library
- URL: `https://www.facebook.com/ads/library/`
- Buscar por: nombre de marca, nombre de página, dominio
- Filtrar por: país (Chile), plataforma (Facebook + Instagram), estado (activos)
- Capturar: cantidad de ads activos, tipo de creativos (imagen, video, carrusel), copy principal, oferta, CTA, fecha de inicio

**Web search queries:**
- `meta ad library [marca]`
- `facebook ads library [marca] chile`
- `[marca] facebook ads`

### Google Ads Transparency Center
- URL: `https://adstransparency.google.com/`
- Buscar por: nombre del anunciante o dominio
- Capturar: presencia de ads, formato (search, display, YouTube), regiones

**Web search queries:**
- `google ads transparency [marca]`
- `[marca] google ads chile`

### TikTok Creative Center
- URL: `https://ads.tiktok.com/business/creativecenter/`
- Buscar por: marca o categoría
- Capturar: tipo de ads, trends, hashtags usados

**Web search queries:**
- `tiktok ads [marca] chile`
- `[marca] tiktok business`

## Análisis de creative strategy

### Tipos de creativos a identificar
| Tipo | Señal | Qué implica |
|------|-------|-------------|
| **Testimonial / UGC** | Video de cliente real, "me cambió la vida" | Social proof strategy, bottom funnel |
| **Educativo** | "¿Sabías que...?", datos, infográficos | Top funnel, awareness + consideration |
| **Oferta directa** | "20% OFF", "Pack ahorro", precio tachado | Bottom funnel, conversión directa |
| **Founder/experto** | CEO o nutricionista hablando a cámara | Authority + trust building |
| **Producto hero** | Foto/video del producto, ingredientes, uso | Mid funnel, consideración |
| **Before/after** | Resultados, transformación | Social proof + conversión |
| **Trending/meme** | Formato viral adaptado a la marca | Awareness, engagement |
| **Comparativa** | "vs. [competidor]" o "no como otros..." | Diferenciación, consideration |

### Análisis de oferta en ads
| Tipo de oferta | Ejemplos | Target |
|---------------|----------|--------|
| Descuento % primera compra | "15% OFF tu primer pedido" | New customer acquisition |
| Envío gratis | "Envío gratis sobre $X" | Reduce fricción, AOV |
| Pack / bundle | "Pack 3 meses ahorra 25%" | LTV, compromiso |
| Social proof como oferta | "100K+ ya confían" | Trust, late consideration |
| Garantía | "Pruébalo 30 días sin riesgo" | Risk reversal, conversión |
| Lead magnet | "Guía gratis de..." | List building, top funnel |
| Nutricionista/experto | "Consulta gratis con compra" | Diferenciación, confianza |
| Free trial / muestra | "Prueba gratis" | Reduce barrera de entrada |

## Competitive ad spend estimation

No tenemos acceso a data de inversión exacta, pero podemos inferir nivel:

| Señal | Nivel estimado |
|-------|---------------|
| 0 ads activos | Nula — sin inversión |
| 1-5 ads, mismos creativos >30 días | Baja — presupuesto mínimo o testing |
| 5-15 ads, rotación ocasional | Media — inversión constante modesta |
| 15-30 ads, múltiples formatos, rotación frecuente | Alta — inversión seria |
| 30+ ads, DPA activo, múltiples plataformas, testing A/B visible | Muy alta — operación de paid media madura |

## Oportunidades de ads por brecha

| Brecha detectada | Oportunidad |
|-----------------|-------------|
| Competidor sin Meta Ads | Espacio libre para capturar audiencia del segmento |
| Competidor sin Google Ads | Keywords de categoría sin competencia pagada |
| Nadie en TikTok Ads | First mover advantage en la plataforma |
| Nadie hace retargeting visible | Todo el tráfico que visita y no compra se pierde |
| Sin DPA activo | Productos vistos no se muestran de vuelta al visitante |
| Ads solo con oferta precio | Oportunidad de diferenciarse con contenido educativo o social proof |
| Sin landing específica para ads | Oportunidad de CRO: landing dedicada > homepage |
